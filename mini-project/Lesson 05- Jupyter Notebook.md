
# 22. Mini Project

## Project Title

**Exploratory Data Analysis (EDA) Dashboard**

### Objective

Create a professional Jupyter Notebook that explores a real dataset and documents the complete analysis.

---

## Folder Structure

```text
Jupyter-EDA/
│
├── README.md
├── requirements.txt
├── .gitignore
│
├── notebooks/
│   └── Student_EDA.ipynb
│
├── data/
│   └── students.csv
│
├── images/
│
└── outputs/
```

---

## Requirements

* Create a notebook with Markdown documentation.
* Load a CSV dataset.
* Display:

  * `head()`
  * `info()`
  * `describe()`
  * Missing values
* Create:

  * Histogram
  * Bar chart
  * Scatter plot
* Write observations below each visualization.
* Save and push the notebook to GitHub.
* Write a professional README.
